## The line

> Mrs. Patel's reading log needed a signature. I signed it with my teeth at 8:02. The ink is still on my tongue.

(110 characters. A named teacher, a specific time, one sensory detail — the ink on the tongue — and one piece of dog logic: the log asked for a signature, so the dog signed it the only way a dog can. The dog believes it did nothing wrong.)
